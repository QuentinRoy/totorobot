# API idea atlas

> **Status:** Not generated. Build this only after the breadth-first waves.

This will be the human-browsable map of the explored design space. It should
make dozens of mechanisms approachable without pretending that the space has
already converged.

## Intended contents

- a short orientation to the territories that emerged;
- several overlapping ways to browse the ideas;
- compact cards for distinct mechanisms;
- visible speculative and outlier regions;
- links from every card back to stable identifiers in
  [`raw-seeds.md`](raw-seeds.md); and
- an explicit list of useful fragments that do not yet form complete APIs.

The atlas may collapse purely cosmetic variants for readability. It must not
hide disagreement, rank clusters, or discard raw seeds.
