# Donor Fragments

This lens selects sharply bounded mechanisms whose value can survive transplantation into otherwise unrelated API families.

## [`W1-B-004`](wave-1-alien-mechanisms.md#w1-b-004) Live Permissive Circuit

It fits because it replaces point-in-time guard checks with a durable safety relationship wherever authorization depends on changing prerequisites. **Precise donor fragment:** model permission as a live conjunction whose loss withdraws the action directly, without requiring a reverse event.

## [`W3-A-001`](wave-3-gaps-a.md#w3-a-001) Possibility-frontier machine

It fits because it gives any API operating under ambiguous, stale, or distributed state an honest rule for exposing safe operations. **Precise donor fragment:** represent current knowledge as a nonempty set of possible worlds and admit a command only when its transition is defined for every member of that set.

## [`W3-D-005`](wave-3-gaps-d.md#w3-d-005) Retractable interpretation

It fits because it makes retroactive evidence usable by derived-state, workflow, cache, and effect APIs without erasing provenance. **Precise donor fragment:** when a supporting fact is retracted, invalidate every dependent derivation and emit inverse deltas for consequences already materialized from it.
