# Alien Mechanism Nominations

Lens: Nominate raw seeds that overturn basic FSM assumptions through genuinely unexpected API mechanisms.

## [W1-B-004: Live Permissive Circuit](wave-1-alien-mechanisms.md#w1-b-004)

An action is not dispatched across a discrete edge; it exists only while a live dependency circuit remains energized and vanishes when any interlock opens. Donor fragment: encode continuously revocable action authority as wiring rather than a snapshot guard.

## [W1-D-012: Consumer-mined protocol](wave-1-impossible-language.md#w1-d-012)

It reverses API authorship by deriving the least legal protocol from typed consumer programs, leaving topology as a mined artifact rather than a provider-authored definition. Donor fragment: treat an unexercised path as absent from the public protocol.

## [W3-A-003: Paraconsistent witness board](wave-3-gaps-a.md#w3-a-003)

It rejects the single-current-state premise: a proposition and its negation may coexist with provenance, while policy grants moves without letting contradiction imply everything. Donor fragment: expose contradictory knowledge as a typed `Both<positiveWitness, negativeWitness>` result.
